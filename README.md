# Sistema de Registro Hospitalario

Proyecto Java Swing para gestión de doctores y pacientes de una clínica.

## Funcionalidades
- Registro de médicos con foto
- Búsqueda por identificación
- Listado completo de médicos
- Registro de pacientes
- Botones funcionales: grabar, consultar, listar, limpiar, salir, pacientes
- Interfaz visual similar al diseño solicitado

## Ejecutar
```bash
javac -d build $(find src -name "*.java")
java -cp build ips.Ips
```
