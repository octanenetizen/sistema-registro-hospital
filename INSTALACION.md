# INSTALACIÓN Y COMPILACIÓN EN NETBEANS\n\n## Paso 1: Descargar el proyecto\n```bash\ngit clone https://github.com/octanenetizen/sistema-registro-hospital.git\ncd sistema-registro-hospital\n```\n\n## Paso 2: Abrir en NetBeans\n1. Abre **NetBeans IDE**\n2. Selecciona **File → Open Project**\n3. Navega a la carpeta descargada `sistema-registro-hospital`\n4. Haz clic en **Open Project**\n\n## Paso 3: Compilar y ejecutar\n1. En NetBeans, presiona **F11** o selecciona **Run → Run Project**\n2. La aplicación se abrirá automáticamente\n\n## Paso 4: Usar la aplicación\n\n### Gestión de Doctores (Ventana principal)\n- **Identificación**: Ingresa el ID del doctor\n- **Nombres**: Nombre(s) del doctor\n- **Apellidos**: Apellido(s) del doctor\n- **Sexo**: Selecciona Masculino o Femenino\n- **Fecha de grado**: Fecha de graduación (formato dd/MM/yyyy)\n- **Cargar imagen**: Carga una foto del doctor\n\n**Botones disponibles:**\n- **Grabar**: Guarda un nuevo doctor o actualiza uno existente\n- **Consultar**: Busca un doctor por ID\n- **Listar**: Muestra todos los doctores registrados\n- **Limpiar**: Limpia todos los campos\n- **Salir**: Cierra la aplicación\n- **Pacientes**: Abre la ventana de gestión de pacientes\n\n### Gestión de Pacientes\n- **Identificación**: ID del paciente\n- **Nombres**: Nombre(s) del paciente\n- **Apellidos**: Apellido(s) del paciente\n- **Fecha de nacimiento**: Fecha de nacimiento (dd/MM/yyyy)\n- **Teléfono**: Número telefónico\n- **Dirección**: Dirección del paciente\n- **Sexo**: Selecciona Masculino o Femenino\n- **Cargar foto**: Carga una foto del paciente\n\n**Botones disponibles:**\n- **Grabar**: Guarda un nuevo paciente\n- **Consultar**: Busca un paciente por ID\n- **Listar**: Muestra todos los pacientes\n- **Limpiar**: Limpia los campos\n- **Cargar foto**: Carga o cambia la foto del paciente\n- **Salir**: Cierra la ventana\n\n## Requisitos\n- **Java 8 o superior**\n- **NetBeans 8.0 o superior**\n\n## Estructura del Proyecto\n```\nsistema-registro-hospital/\n├── src/ips/\n│   ├── Ips.java                    (Clase principal)\n│   ├── Doctor.java                 (Modelo Doctor)\n│   ├── Paciente.java               (Modelo Paciente)\n│   ├── DoctorManager.java          (Gestor de Doctores)\n│   ├── PacienteManager.java        (Gestor de Pacientes)\n│   ├── CargarFoto.java             (Ventana para cargar fotos)\n│   ├── gestionDoctores.java        (Interfaz Gestión de Doctores)\n│   └── gestionPacientes.java       (Interfaz Gestión de Pacientes)\n├── build.xml                       (Script Ant)\n├── manifest.mf                     (Manifest del JAR)\n└── nbproject/                      (Archivos de configuración NetBeans)\n```\n\n## Notas\n- Los datos se almacenan en memoria (ArrayList)\n- Soporta formatos de imagen: JPG, JPEG, PNG\n- Las fechas deben ingresarse en formato dd/MM/yyyy\n- Los cambios se pierden al cerrar la aplicación (versión en desarrollo)\n\n## Próximas versiones\n- Integración con base de datos (MySQL/PostgreSQL)\n- Persistencia de datos\n- Sistema de login\n- Más especialidades médicas\n"
